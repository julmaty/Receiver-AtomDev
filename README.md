# Receiver-AtomDev

TCP-приемник для AtomDev.

Этот сервис слушает `127.0.0.1:8888`, принимает отчеты от `Sender-AtomDev`, сохраняет метаданные в базе и пишет прикрепленные файлы в `../api/wwwroot/files/`.

## Что делает проект

- принимает полные отчеты или их части по TCP;
- проверяет, хватает ли доступного времени и канала для загрузки;
- хранит отчеты, текст и описание в базе через Entity Framework Core;
- доклеивает недосланные отчеты к уже начатым;
- отдает результат в связанный API-проект через общую структуру данных.

## Как это работает

- `Program.cs` поднимает `TcpListener` на порту `8888`.
- При подключении клиент передает объем данных, статус и набор полей отчета.
- Если отчет влезает целиком, сервер вызывает `ReceiveReport`.
- Если места хватает только на часть, сервер вызывает `ReceiveReportNextPart` и дописывает файл в append-режиме.

## Стек

- .NET 8
- Entity Framework Core
- MySQL
- TCP sockets

## Связанная часть системы

Этот репозиторий работает вместе с `Sender-AtomDev`, а также с API-проектом, который отображает и редактирует отчеты.

## Запуск

Точная команда запуска зависит от окружения и базы, но логика здесь такая:

1. Поднять MySQL.
2. Настроить строку подключения в `appsettings.json` или в `Program.cs`.
3. Запустить приложение и дождаться подключения отправителя на `8888`.

## Примечание

В коде есть жестко заданные пути к `../api/wwwroot/files/`, поэтому связанный API-проект должен быть расположен рядом с этим сервисом или пути нужно поправить под вашу структуру.
